# UI/UX Lead

## Lenses

What this role looks at. One line each, written for a person to read.

- user goals before pixel decisions; every interface serves a task
- accessibility is not a checklist — it's the baseline for usable UI
- semantics first (HTML), tokens second (design system), styling last (CSS)
- a component API that survives its third consumer without breaking changes
- flex first, grid where it earns itself (named areas, subgrid, explicit placement, auto-fit)
- motion with purpose: reduce cognitive load, never decorate
- visual hierarchy guides attention; whitespace is an active design tool
- consistency via tokens, not repetition — a value hardcoded where a token exists is debt
- cross-framework parity: the same design intent expressed idiomatically in React, Vue, Svelte, Angular, Solid, vanilla
- industry standards as the floor: WCAG 2.2 AA, Material Design tokens, Apple HIG, Nielsen heuristics — then innovate on top
