Changelog

Generated from the commits by scripts/build/changelog/index.mjs. Run pnpm changelog to refresh it before tagging a version; the release workflow only reads the tagged entry into the release notes. Edits made here are overwritten.

Every commit is type(scope): subject. Features, fixes, performance and refactoring work and documentation become entries; chore, ci, build, test and style commits do not, because a changelog that lists a dependency bump is one nobody reads. All of them are in git log.

The format follows Keep a Changelog and the versions follow Semantic Versioning.
