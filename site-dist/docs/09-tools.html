09 - Tools

Counted from the registries that define it. Run pnpm census after changing a tool, a skill, a prompt, a role, a command or a guardrail; tests/docs/census-generated.test.mjs compares this file against the live registry, so a stale copy fails the build instead of misleading a reader.

Action tools (17)

The tools that do something rather than serve a skill. Every one is deterministic: none of them calls a model, so the same arguments return the same result behind any client.

pix_tool

Route prompt to correct rule skill. Returns structured routing with relevant sections.

Parameter Type Required Default Description
prompt string yes - User's question about frontend development
framework string no - Optional framework hint (react, vue, svelte, angular, etc.) to bias routing
path string no - Optional project path for auto-detecting framework

rule_tool_update

Force-update this local MCP server from its upstream git repo (fast-forward only), hot-reload skills, and restart if server code changed. Also runs automatically (throttled, in background) on tool calls; call directly to update on demand.

Takes no parameters.

rule_tool_gateway

Single-entry orchestrator: routes prompt → loads skill evidence → checks code against guardrails → returns receipt. Use this as primary entry point instead of calling rule + skill tools separately. returned receipt must be passed to rule_tool_apply when writing files.

Parameter Type Required Default Description
prompt string yes - Complete coding request
code string no - Code to validate against guardrails (single file)
files array of object no - Files to validate - yields a path-bound receipt, required for multi-file writes
path string no - Project path for framework auto-detection
framework string no - Target framework (react, vue, svelte, angular, solid, astro, vanilla, express, fastify, nestjs, hono)

rule_tool_apply

Write files to disk after rule_tool_gateway validation. Needs valid receipt from rule_tool_gateway proving that code passed all guardrails. receipt is tied to exact code hash - modified code will be rejected. Use dryRun=true (default) to preview without writing.

Parameter Type Required Default Description
files array of object yes - Array of files to create/write
receipt string yes - Receipt token from rule_tool_gateway that validated this exact code
path string no "." Project root directory
dryRun boolean no true Preview without writing (default: true)

rule_tool_search

Semantic search across ALL rule skills using BM25 ranking. Returns scored, relevant sections.

Parameter Type Required Default Description
query string yes - Search query to find across all rule skills
maxResults integer no 10 Maximum number of ranked results

rule_tool_check

Run guardrail checks on code against any rule skill. Returns guardrail results with re-check hint containing current passing set. Run until allPass: true.

Parameter Type Required Default Description
skill string yes - Target rule skill name
code string yes - Code to validate against guardrails
framework string no - Framework (react, vue, svelte, angular, solid, astro, vanilla)
fileName string no - File name for naming convention checks
isComponent boolean no - Whether this is a component file
mode string no - Check mode (e.g. 'scaffold' to validate project config files)
allowedDependencies array of string no - Manifest-derived package names allowed in imports

rule_tool_scaffold

Parameter Type Required Default Description

file string no - Specific file to generate (omit for all)
projectDir string no - Project root path (for validate mode)
framework string no - Framework hint (tsconfig only for TS projects)

rule_tool_detect

Detect project framework, TypeScript usage, and build tool from package.json.

Parameter Type Required Default Description

rule_tool_compress

Compress prose deterministically: strip filler and leading articles, replace typographic characters with ASCII, convert British spelling to American. Code, inline spans, URLs and JSON are never touched.

Parameter Type Required Default Description
text string yes - Prose to compress. Code fences, inline code, URLs and JSON pass through untouched
mode both | compression | fingerprint no "both" both (default), compression (filler only), fingerprint (punctuation and spelling only)
fileName string no - Where the prose came from, when it came from a file. A sensitive name (.env, credentials, id_rsa, anything under .ssh) is refused
