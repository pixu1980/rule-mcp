Hooks (3 entries across 3 events)

Written into the host's settings file by install --agent claude, and removed by uninstall. Every entry carries a marker comment, which is how a merge and an uninstall find ours without touching anyone else's. Each one answers ask, never deny: these are judgment calls with a human in the room, and a hard block on a false positive costs more than the prompt it saves.
