12 - CLI

Counted from the registries that define it. Run pnpm census after changing a tool, a skill, a prompt, a role, a command or a guardrail; tests/docs/census-generated.test.mjs compares this file against the live registry, so a stale copy fails the build instead of misleading a reader.

The commands (22)

Every command is listed with the arguments and options it reads, taken from the commander definitions that parse them. The same definitions answer rule-mcp <command> --help, so nothing here is a promise the binary does not keep.

rule-mcp with no command starts the stdio server, which is how an agent spawns it. -h, --help works on every command; -v, --version prints the package version from anywhere. An error exits 1 and prints to stderr; --help exits 0.
