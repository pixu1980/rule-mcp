08 - Skills

Counted from the registries that define it. Run pnpm census after changing a tool, a skill, a prompt, a role, a command or a guardrail; tests/docs/census-generated.test.mjs compares this file against the live registry, so a stale copy fails the build instead of misleading a reader.

Skills (89)

The catalog. A skill is the source of truth for its topic; the tool that serves it carries no rules of its own, and the guardrails it is checked against are in 14-guardrails.md.

The router's own directory, skills/rule/, mints no skill tool, which is why the catalog is 89 and the directory count is 90.
