14 - Guardrails

Counted from the registries that define it. Run pnpm census after changing a tool, a skill, a prompt, a role, a command or a guardrail; tests/docs/census-generated.test.mjs compares this file against the live registry, so a stale copy fails the build instead of misleading a reader.

Guardrail rules (95 distinct)

Deterministic checks, run by rule_tool_check and by the repository against itself. A rule can belong to more than one family, so the family counts sum to more than the distinct total, and a check names the skill it runs for: the shared rules always, plus whatever that skill's area adds.

Family Rules Applies to
a11y 9 Any check on markup or a component
angular 1 A check against a rule-frontend-angular skill
backend 6 A check against a rule-backend-* skill
database 4 A check against a rule-data-* skill
devops 4 A check against a rule-devops-* skill
file_tree 4 A check that is given a file tree rather than one file
framework:astro 20 A check whose framework is Astro
framework:solid 20 A check whose framework is Solid
framework:vanilla 20 A check with no framework named
framework:vanilla-reactive 29 A check on a reactive vanilla component
js 16 Any JavaScript or TypeScript source
quality 16 Every check: types, manifests, prose, comments, simplicity
react 2 A check against a rule-frontend-react skill
scaffold 8 Generated project scaffolding
shared 17 Every check, whatever the skill
simplicity 3 Every check: the rules that reject code nothing asked for
svelte 1 A check against a rule-frontend-svelte skill
vanilla_reactive 9 A reactive vanilla component, no framework
vue 1 A check against a rule-frontend-vue skill

a11y

Rule Label What it rejects Also in
a11y-img-alt Images carry a text alternative Every img needs alt. An empty alt is a valid answer for decoration; a missing one is not an answer at all. -
a11y-positive-tabindex No positive tabindex A positive tabindex takes the element out of document order, so focus order stops matching reading order. -
a11y-html-lang The page declares its language Without lang, a screen reader picks a voice by guess and pronounces the page in the wrong language. -
a11y-iframe-title Frames are named An iframe with no title is announced as "frame", which tells the user nothing about whether to enter it. -
a11y-aria-hidden-focusable Nothing focusable is aria-hidden aria-hidden on a focusable element leaves it in the tab order while removing it from the accessibility tree, so focus lands on nothing announceable. -
a11y-no-autoplay Media does not autoplay with sound Audio starting on load competes with a screen reader and cannot be stopped by someone who has not found the control yet. -
a11y-video-captions Video offers captions A video element with no captions track excludes anyone who cannot hear it, and anyone in a room where sound is not an option. -
a11y-form-label Inputs are labeled An input with no label, aria-label or aria-labelledby is announced by its type alone, so the user hears "edit text" and nothing else. -
a11y-focus-visible Focus stays visible Removing the outline without replacing it leaves keyboard users with no way to see where they are. -

helmet-headers Security headers via helmet HTTP security headers should be set via helmet or framework equivalent. -

parameterized-queries Parameterized database queries Queries must use placeholders ($1, ?, :name), not string concatenation. -
transaction-safety Multi-statement transactions Multiple mutations should be wrapped in a transaction. -
connection-pool Connection pooling Database clients should use connection pooling with explicit max pool size. -
