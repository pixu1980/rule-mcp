Trademark

"rule-mcp" names this project. The name is not a registered trademark; this file states the posture until one exists, so a fork knows the boundary before crossing it.

What you may do without asking

  • Fork the repository under a different name.
  • Reference the package name in text: dependency lists, install instructions, compatibility statements ("works with rule-mcp").
  • Name a fork something-rule-mcp only if the name cannot read as the project itself - when in doubt, ask first.

What requires permission

  • Anything that implies endorsement: presenting a fork, service, or paid offering as the project, or using the name in a product title, logo, or domain. Ask at pisuemiliano.1980@gmail.com.

What the code license does not grant

The MIT license covers the code. It grants no trademark rights: you may copy, modify and distribute the software, but not present your copy as us, or us as endorsing you.

The npm name question

The rule-mcp name on the npm registry is unclaimed, and npm publication is out of scope by decision (see the naming ADR). Whether to hold the name with a placeholder or to record the squat risk is an open owner decision; it is recorded in the ADR below, not silently left.
