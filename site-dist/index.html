    Deterministic skills for every AI coding agent, without calling an LLM.

    An MCP server that routes free-text requests to the right skill, serves styleguides and templates as tools and resources, and validates generated code with guardrails. Same behavior behind Claude, GPT, Gemini, Llama, or Qwen. Local-first. Model-agnostic.

    How it works

    1. Route. A free-text request reaches the router, which picks the matching skill or area hub.
    2. Serve. Skills arrive as MCP tools, resources, and prompts as evidence, not opinions.
    3. Validate. Deterministic guardrails check generated code before it lands.
