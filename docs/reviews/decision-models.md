# decision-models review

- **Role**: decision-models v1
- **Date**: 2026-10-20

Findings distilled from [the audit](../audits/decision-models.md). A finding this run no longer reports is flipped to resolved and kept one run for visibility, then removed.

| Finding | Severity | Status   | Evidence                                                  | Summary                                                                                                                                                                              |
| ------- | -------- | -------- | --------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| DM-01   | high     | resolved | docs/audits/decision-models.md#prototype-measurements     | `confidence` is a normalized score, not a probability: the router reports `1` for an `unknown` route with `uncertain: true`, so no caller can threshold it                           |
| DM-02   | high     | resolved | docs/audits/decision-models.md#prototype-measurements     | A decision-model rerank of the BM25 top five fixes 3 of 13 addressable misses, and nothing in the suite would stop shipping it if it fixed 0                                         |
| DM-03   | high     | resolved | docs/audits/decision-models.md#what-the-server-does-today | No decision client exists, and the server makes no outbound HTTP call today, so the first one adds a dependency to the request path with no invariant                                |
| DM-04   | high     | open     | docs/audits/decision-models.md#prototype-measurements     | Non-English prompts fail: 3 of 4 Italian prompts route to `unknown`, and the only installed decision model is English-only                                                           |
| DM-05   | medium   | resolved | docs/audits/decision-models.md#prototype-measurements     | Nothing bounds the option set: 83 options in one `choice` picked the intended skill once in 13 and was confidently wrong (`ui`, confidence 0.999)                                    |
| DM-06   | medium   | resolved | docs/audits/decision-models.md#findings                   | The model lifecycle has no supervisor: `load` answers before the model is ready, 519 ms and 8867 ms loads were measured, `max_instances 1` returns `500 model limit reached`         |
| DM-07   | medium   | resolved | docs/audits/decision-models.md#findings                   | Determinism is proven (repeat delta 0.000000) but untested as a property: no cache key, no replay, nothing invalidates an answer when the model changes                              |
| DM-08   | medium   | resolved | docs/audits/decision-models.md#what-the-server-does-today | 88 guardrail rules are all structural; there is no semantic (meaning-level) family, and the `advisory` flag is used only by the graph checks                                         |
| DM-09   | low      | resolved | docs/audits/decision-models.md#prototype-measurements     | Three corpus entries expect a skill name no skill carries (`backend-api-design`, `ai-agents`, `devops-gitlab-ci`), so the 81% baseline is measured with a ruler that cannot be right |
| DM-10   | low      | open     | docs/audits/decision-models.md#what-the-server-does-today | Persona finding severity is assigned by the agent with no normalization, so two runs can disagree about the same evidence                                                            |
| DM-11   | low      | resolved | docs/audits/decision-models.md#reproduction               | No environment variable, ADR, census entry or README count exists for a decision endpoint, and the counts are enforced by tests                                                      |
| DM-12   | medium   | resolved | docs/audits/decision-models.md#what-the-server-does-today | Nothing stops an operator from pointing a decision URL at a remote host, which would send prompt text off the machine the privacy statement promises                                 |

DM-04 and DM-10 remain open: the Italian slice still measures 2/8 exact, 3/8 top-or-alternative and 5/8 `unknown` with Julia-1 installed as `ggml-org/Julia-1-GGUF:Q8_0`, so the routing claim stays dropped; the severity normalizer was rejected because the review labels are the agent's own, so the agreement measurement would be circular. DM-07's cache is short-circuited before the runtime: a cached Italian prompt that follows an English one makes no `/models` or `/v1/systemone` request, so the router does not swap back.
