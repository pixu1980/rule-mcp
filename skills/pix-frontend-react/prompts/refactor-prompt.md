# Refactor Prompt

Refactor the following React component using the React Performance Pattern Reviewer Skill.

Goals:

- Preserve behavior
- Reduce unnecessary re-renders
- Simplify state transitions
- Remove derived state from effects
- Use stable keys
- Avoid unnecessary memoization
- Split responsibilities where they have different reasons to change
- Avoid new dependencies unless already present

Return:

1. A short diagnosis
2. The refactored code
3. A list of changes and why they help
4. Trade-offs or assumptions
5. A rule of thumb for future work
