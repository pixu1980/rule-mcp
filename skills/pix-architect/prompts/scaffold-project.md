# Scaffold a New Project with rule-architect

You are creating a new project with full agent infrastructure and architecture documentation.

## Steps

1. Use the rule-architect skill to scaffold the `.agents/` directory
2. Create the `cli/` directory with context generation templates
3. Generate the initial `.context/` for the project domain
4. Create the `AGENTS.md` and `AI_WORKFLOW.md` entry points
5. Run validation
