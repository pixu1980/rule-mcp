# Luma Bookmarks

Luma is a quiet, accessible bookmarks manager for people who collect links with intention. Paste a public URL, let the API read its metadata and article text, inspect the preview, then save it to your library.

## Product principles

- **Preview before persistence** — remote content is fetched before a bookmark is saved.
- **Readable by default** — semantic HTML, keyboard focus, WCAG 2.2 AA targets, and reduced-motion support.
- **Private by design** — no accounts or tracking in the local-first demo.
- **One visual language** — proportional typography, spacing, radii, elevations, and motion tokens.

## Aesthetic direction

Luma uses a refined editorial desk: warm paper, graphite ink, a single citrus accent, and a serif display voice. The memorable detail is the oversized italic “matters” paired with a floating dark preview card.
